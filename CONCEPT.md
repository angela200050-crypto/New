# Один объект — несколько продолжений

Интерактивная страница знакомит с нодовой системой через короткую историю одного трамвая. Пользователь сначала видит три разных маршрута и несколько форматов результата: изображение, видеопревью, звук и сценарий. Отдельная схема показывает путь промпта, референса героя и стиля к изображению, а затем к видео. Затем пользователь выбирает кадр и раскрывает его устройство.

## Пользовательский сценарий

1. Выбрать кадр в раскадровке.
2. Увидеть общую исходную ноду героя и отдельные ноды места, света и движения камеры.
3. Изменить одно решение и проследить подсвеченную связь до обновлённого кадра.
4. Посмотреть обновлённый результат. Вернуться к раскадровке или повторить опыт с другим кадром.

Настройки каждого кадра сохраняются независимо. У места, света и камеры по три варианта. Например, ночной горный перевал получается из сочетания «Горы» и «Ночь» без сброса других решений.

## Почему это объясняет ноды

Нода выполняет одну понятную роль. Связь показывает, как её решение участвует в сборке кадра. Один исходный объект используется повторно, а пользователь может менять только нужную часть. Анимация движется по затронутым связям и заканчивается обновлением результата; на узких экранах та же причинная последовательность показана вертикально.

Это демонстрационный прототип с подготовленными изображениями, черновым видеопревью с движением виртуальной камеры и синтезированным звуковым эскизом. Готовый видеоролик может заменить превью без изменения структуры страницы. Сценарий написан для демонстрации формата результата. Эти материалы показывают предполагаемый пользовательский сценарий, а не подтверждённые возможности работающего продукта; настоящей AI-генерации здесь нет.
